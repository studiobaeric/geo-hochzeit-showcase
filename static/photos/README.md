# Hochzeitsfotos

Lege hier deine Hochzeitsfotos ab, die im Spiel verwendet werden sollen.
Die restliche Spiel-Konfiguration (Spielernamen, Profilfotos, Rundenfotos
mit Orten) liegt gesammelt in [`static/config/`](../config/).

## Format
- Unterstützte Formate: JPG, PNG
- Dateinamen müssen mit den Einträgen in `static/config/photos.json` übereinstimmen

## Beispiel
Wenn in `photos.json` ein Foto mit `"filename": "brautpaar.jpg"` definiert ist, muss hier eine Datei `brautpaar.jpg` existieren.
